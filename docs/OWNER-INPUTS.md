## Required response format

For each blocker, return:

1. accountable owner and backup;
2. direct answer to every question;
3. secure evidence link or record identifier;
4. approved public wording, if applicable;
5. approval date and recheck/expiry date;
6. unresolved exceptions.

Anything unanswered remains `pending`; claim/adjuster language remains `quarantined`. Do not place customer PII, credentials, contracts, releases, claim files, or private CRM exports in the Git repository.
